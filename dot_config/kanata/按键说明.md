| 组合 | 行为 |
|---|---|
| `Caps` 点按 | 切换 CapsLock |
| `Caps+S/D/E/F` | 左/下/上/右移动 |
| `Caps+P/;` | 行首/行尾 |
| `Caps+H/J/K/L` | 向左/下/上/右选中 |
| `Caps+W/R` | Backspace/Delete |
| `Caps+Q`、`Caps+Backspace` | 清除当前行内容，保留换行 |
| `Caps+[/]` | 删除到行首/行尾 |
| `Caps+Enter` | 在行尾换行 |
| `Caps+Alt+D/E` | 下移/上移 5 行 |
| `Caps+Alt+H/L` | 选中到行首/行尾 |
| `Caps+Alt+J/K` | 向下/向上选中 5 行 |
